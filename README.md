# FTA Portfolio

Personal portfolio site for **Fifi Trista Andriyani**.

## Structure

```
portfolio/
├── index.html
├── css/style.css
├── js/script.js
└── assets/
    ├── documents/   # CV
    └── images/      # photos, certificates, projects, icons
```

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Notes

- Edit content in `index.html` and data in `js/script.js`.
- Place new images under `assets/images/` (projects, activities, certificates, icons).
